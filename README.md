# Epiora

A local-first, open-core successor to CDC's Epi Info: forms, offline data entry, validated epidemiological
analysis, outbreak tools and reports, from a laptop or a low-end phone.

Status: **v0.1 — technical spikes.** Nothing here is usable yet.
