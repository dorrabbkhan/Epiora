**Conventions.**

- Input types per the plan: `count` (non-negative integer < 2^53) · `integer` · `real` ·
  `proportion` in (0,1) · `percent` in [0,100] · `conf_level` · `choice[...]` ·
  `table[rows×cols, min..max rows]`. `conf_level` is `choice[90,95,99]` per spec §5.3
  (OpenEpi accepts more levels in some modules — noted per calculator).
- Statistic ids are `calc.<id>.<path>`; every id is a `validation` registry row and gets a
  fixture (global constraints).
- Tolerance classes: `closed_form` 1e-9, `iterative` 1e-6 (root-found or iteratively
  summed values). Exact/mid-p CIs and tests are `iterative`; everything else
  `closed_form`. R references use `uniroot(tol = 1e-14)` where iterative.
- "OE" column: OpenEpi prints most estimates and CI bounds at 4 significant figures
  (`fmtSigFig(·,4)` → marked "4sf"), p-values via `fmtPValue`, sample sizes via
  `Math.ceil`; exact decimals per value are captured by Task 3. "EI7" column: whether
  Epi Info 7 StatCalc shows the statistic (it displays at F4–F7 decimals).
- `fixtures/R/methods/<file>.R::fn` names a function Task 2 writes; each carries a
  literature source. All other references are real R functions (see "R packages").

four-function arithmetic calculator, not a statistical calculator. OpenEpi Home, Info and

**Id merges** (reason per plan): OpenEpi's three separate power pages Cohort, Clinical
Trial and X-Sectional share one computation — same inputs (two group sizes, two

in labels — so they map to one calculator `power_cohort` with a `design` input. EI7's
"Tables (2x2, 2xN)" is stratified 2×2 (2×2×N), kept as its own calculator `two_by_n`
because its output set is EI7's StatCalc statistics block, not OpenEpi's.

## proportion  (family: counts)

- Sources: OpenEpi page <https://www.openepi.com/Proportion/Proportion.htm> (+ `Proportion.js`) · EI7 StatCalc: none (nearest EI7 outputs are FREQ's Clopper–Pearson limits)
- Inputs:
  - `numerator` · count · 0..denominator · default 10
  - `denominator` · count · ≥0 · default 11
  - `conf_level` · conf_level · 90/95/99 · default 95
  - `multiplier` · real · >0 · default 100 (display scale only, e.g. per 100)
  - `population_size` · integer · ≥ denominator, 0 = infinite · default 1 000 000 (OpenEpi applies a finite-population correction only when 2 < N < 1 000 000)
  - `compare_with` · percent · 0–100 · default 50 · optional one-sample test (omit to skip)
- Outputs (`× multiplier` where marked):
  - `calc.proportion.estimate` · proportion x/n · `stats::prop.test$estimate` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.midp.{lower,upper}` · mid-p exact CI · bisection on binomial tail · `exactci::binom.exact(midp=TRUE)` · iterative · OE 4sf / EI7 no
  - `calc.proportion.ci.clopper_pearson.{lower,upper}` · Fisher exact (Clopper–Pearson) CI · `stats::binom.test` · iterative · OE 4sf / EI7 no
  - `calc.proportion.ci.wald.{lower,upper}` · Wald (normal approx.) CI · p̂ ± z√(p̂q̂/n), truncated [0,1] · `PropCIs::wald2ci` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.agresti_coull.{lower,upper}` · modified Wald CI · `PropCIs::addz2ci` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.wilson.{lower,upper}` · Wilson score CI (OpenEpi "Editor's choice") · `PropCIs::scoreci` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.wilson_fpc.{lower,upper}` · Wilson score with finite-population correction (only when FPC applies) · `fixtures/R/methods/proportion.R::wilson_fpc_ci` — Wilson score with √((N−n)/(N−1)) factor as in OpenEpi `Proportion.js` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.score_cc.{lower,upper}` · score CI with continuity correction (Fleiss quadratic) · `fixtures/R/methods/proportion.R::score_cc_ci` — Fleiss, Statistical Methods for Rates and Proportions · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ztest.{z,p}` · one-sample z-test vs `compare_with` (normal-theory binomial test; OpenEpi also flags npq < 5) · `stats::prop.test(correct=FALSE)` · closed_form · OE 4sf / EI7 no
- Method differences: OpenEpi skips mid-p/Fisher when n > 100 001 (device safeguard — Epiora has no such cap). OpenEpi's conf list is site-wide 20–99.99%; Epiora uses the §5.3 list.

## matched_case_control  (family: counts)

- Sources: OpenEpi page <https://www.openepi.com/MatchCC/MatchCC.htm> (+ `MatchCC.js`, `js/MartinStats.js::matchedCC`) · EI7 StatCalc `EpiDashboard/Gadgets/StatCalc/MatchedPairCaseControlGadget` + `EpiDashboard/Controls/MatchedPairPanel.xaml(.cs)` + `Epi.Statistics/pmccTable.cs` — both reference tools are 1:1 pairs only; the 1:n path below is Epiora's own implementation (owner decision, 2026-11-13, via the conductor, PR #62)
- Inputs:
  - `controls_per_case` · integer · 1..4 · default 1 — controls per matched case (M). Upper bound 4: the efficiency of M controls per case relative to an unlimited number is M/(M+1) (Breslow & Day 1980, ch. 5), so M = 4 already reaches 80% and larger ratios add little precision; flagged for the owner in the PR body.
  - `matched_sets` · `table[2 × (M+1)]` — matched-set counts classified by case exposure (exposed/unexposed rows) × number of exposed controls in the set (0..M columns); counts ≥0. For M = 1 this is the 2×2 pair table: its four cells are exactly the concordant-exposed pair, discordant b (case exposed/control unexposed), discordant c (case unexposed/control exposed) and concordant-unexposed pair, so the pair table is shown as the M = 1 special case of this table — one input structure, and the OpenEpi/EI7 pair layout is unchanged.
  - `conf_level` · conf_level · default 95
  - Variable ratios (different M per set): out — a set's conditional-likelihood contribution depends on both its exposed-control count and its own M, so mixed-M data cannot be summarised in a 2×(M+1) set table and would need set-level input; neither reference tool has it. Flagged for the owner in the PR body.
- Outputs, 1:1 pairs (M = 1) — compared with OpenEpi and Epi Info 7:
  - `calc.matched_case_control.mcnemar.{value,p}` · McNemar χ² (df 1, uncorrected) · `stats::mcnemar.test(correct=FALSE)` · closed_form · OE 4sf / EI7 yes (F4/F10)
  - `calc.matched_case_control.mcnemar_cc.{value,p}` · McNemar with continuity correction · `stats::mcnemar.test(correct=TRUE)` · closed_form · OE 4sf / EI7 yes
  - `calc.matched_case_control.or.{est,lower,upper}` · pair-matched OR b/c, Taylor CI · `fixtures/R/methods/matched.R::matched_or_taylor` — b/c with log CI √(1/b+1/c) · closed_form · OE 4sf / EI7 yes
  - `calc.matched_case_control.cmle_or.midp.{est,lower,upper}` · conditional MLE OR with mid-p limits · `exact2x2::exact2x2(paired=TRUE, midp=TRUE)` · iterative · OE 4sf / EI7 no
  - `calc.matched_case_control.cmle_or.fisher.{lower,upper}` · Fisher exact limits on the pair-matched OR · `exact2x2::exact2x2(paired=TRUE, tsmethod="central")` · iterative · OE 4sf / EI7 yes
  - `calc.matched_case_control.exact.midp_p` · mid-p exact test on discordant pairs · `exact2x2::exact2x2(paired=TRUE, midp=TRUE)` · iterative · OE fmtPValue / EI7 no
  - `calc.matched_case_control.exact.fisher_{p_1t,p_2t}` · Fisher exact test (binomial on discordants) · `stats::binom.test` on discordants · iterative · OE fmtPValue / EI7 yes (Fisher 1t + 2t, F10)
  - `calc.matched_case_control.discordant_pairs` · count b+c — input-derived · `fixtures/R/methods/matched.R::discordant_pairs` — discordant pair count b+c as in OpenEpi `MatchCC.js` / EI7 `pmccTable.cs` · closed_form · OE yes / EI7 yes
- Outputs, 1:n (M ≥ 2) — no OpenEpi or EI7 reference; validated against R only (owner decision):
  - `calc.matched_case_control.matched_n.mh_or.{est,lower,upper}` · Mantel–Haenszel OR over matched sets, each set one 2×2 stratum (case vs pooled controls × exposed/unexposed); reduces to b/c at M = 1 · `stats::mantelhaen.test` · closed_form · OE no / EI7 no
  - `calc.matched_case_control.matched_n.mh_chisq.{value,p}` · Mantel–Haenszel χ² over matched sets, uncorrected — the generalised McNemar for 1:n (df 1) · `stats::mantelhaen.test(correct=FALSE)` · closed_form · OE no / EI7 no
  - `calc.matched_case_control.matched_n.mh_chisq_cc.{value,p}` · Mantel–Haenszel χ² over matched sets with continuity correction · `stats::mantelhaen.test(correct=TRUE)` · closed_form · OE no / EI7 no
  - `calc.matched_case_control.matched_n.cmle_or.{est,lower,upper}` · conditional-MLE OR from conditional logistic regression, one stratum per matched set; Wald CI on the coefficient · `survival::clogit` · iterative · OE no / EI7 no
- Method differences: both reference tools flag "use only exact results" when discordant pairs < 20 — Epiora emits the diagnostics rather than hiding output. The 1:n outputs have no OpenEpi or EI7 reference and are validated against R only (owner decision, 2026-11-13); at M = 1 the MH matched OR equals b/c, matching `calc.matched_case_control.or.est`.
