**Sources read.** Live OpenEpi 3.01 (menu `js/menuitems.js`; each module's `.htm` input
table and `.js` statistics, fetched 2026-11-13, one fetch per page — see "OpenEpi terms of
use") and the Epi Info 7 StatCalc source in `Epi-Info/Epi-Info-Community-Edition`
@ `4cd353c62c40b78d9d1f013b0f5a2bb685a5fca6` (see "Epi Info 7 StatCalc source").

**Conventions.**

- Input types per the plan: `count` (non-negative integer < 2^53) · `integer` · `real` ·
  `proportion` in (0,1) · `percent` in [0,100] · `conf_level` · `choice[...]` ·
  `table[rows×cols, min..max rows]`. `conf_level` is `choice[90,95,99]` per spec §5.3
  (OpenEpi accepts more levels in some modules — noted per calculator).
- Statistic ids are `calc.<id>.<path>`; every id is a `validation` registry row and gets a
  fixture (global constraints).
- Tolerance classes: `closed_form` 1e-9, `iterative` 1e-6 (root-found or iteratively
  summed values). Exact/mid-p CIs and tests are `iterative`; everything else
  `closed_form`. R references use `uniroot(tol = 1e-14)` where iterative.
- "OE" column: OpenEpi prints most estimates and CI bounds at 4 significant figures
  (`fmtSigFig(·,4)` → marked "4sf"), p-values via `fmtPValue`, sample sizes via
  `Math.ceil`; exact decimals per value are captured by Task 3. "EI7" column: whether
  Epi Info 7 StatCalc shows the statistic (it displays at F4–F7 decimals).
- `fixtures/R/methods/<file>.R::fn` names a function Task 2 writes; each carries a
  literature source. All other references are real R functions (see "R packages").

**Excluded menu items** (with reason): OpenEpi `Calculator/calculator.htm` — a
four-function arithmetic calculator, not a statistical calculator. OpenEpi Home, Info and
Help (About, News, Choosing a method, Using OpenEpi, Credits, Licensing, History),
Language/Options/Settings, and Searches (Google, PubMed) — navigation/documentation, not
calculators. No statistical menu item is dropped.

**Id merges** (reason per plan): OpenEpi's three separate power pages Cohort, Clinical
Trial and X-Sectional share one computation — same inputs (two group sizes, two
proportions), same outputs (normal approximation ± continuity correction), differing only
in labels — so they map to one calculator `power_cohort` with a `design` input. EI7's
"Tables (2x2, 2xN)" is stratified 2×2 (2×2×N), kept as its own calculator `two_by_n`
because its output set is EI7's StatCalc statistics block, not OpenEpi's.

## proportion  (family: counts)

- Sources: OpenEpi page <https://www.openepi.com/Proportion/Proportion.htm> (+ `Proportion.js`) · EI7 StatCalc: none (nearest EI7 outputs are FREQ's Clopper–Pearson limits)
- Inputs:
  - `numerator` · count · 0..denominator · default 10
  - `denominator` · count · ≥0 · default 11
  - `conf_level` · conf_level · 90/95/99 · default 95
  - `multiplier` · real · >0 · default 100 (display scale only, e.g. per 100)
  - `population_size` · integer · ≥ denominator, 0 = infinite · default 1 000 000 (OpenEpi applies a finite-population correction only when 2 < N < 1 000 000)
  - `compare_with` · percent · 0–100 · default 50 · optional one-sample test (omit to skip)
- Outputs (`× multiplier` where marked):
  - `calc.proportion.estimate` · proportion · x/n · `stats::prop.test` (or x/n) · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.midp.{lower,upper}` · mid-p exact CI · bisection on binomial tail · `exactci::binom.exact(tsmethod="midp")` · iterative · OE 4sf / EI7 no
  - `calc.proportion.ci.clopper_pearson.{lower,upper}` · Fisher exact (Clopper–Pearson) CI · `stats::binom.test` · iterative · OE 4sf / EI7 no
  - `calc.proportion.ci.wald.{lower,upper}` · Wald (normal approx.) CI · p̂ ± z√(p̂q̂/n), truncated [0,1] · `PropCIs::wald2ci` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.agresti_coull.{lower,upper}` · modified Wald CI · `PropCIs::addz2ci` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.wilson.{lower,upper}` · Wilson score CI (OpenEpi "Editor's choice") · `PropCIs::scoreci` (or `epitools::binom.wilson`) · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.wilson_fpc.{lower,upper}` · Wilson score with finite-population correction (only when FPC applies) · `fixtures/R/methods/proportion.R::wilson_fpc_ci` — Wilson score with √((N−n)/(N−1)) factor as in OpenEpi `Proportion.js` · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ci.score_cc.{lower,upper}` · score CI with continuity correction (Fleiss quadratic) · `fixtures/R/methods/proportion.R::score_cc_ci` — Fleiss, Statistical Methods for Rates and Proportions · closed_form · OE 4sf / EI7 no
  - `calc.proportion.ztest.{z,p}` · one-sample z-test vs `compare_with` (normal-theory binomial test; OpenEpi also flags npq < 5) · `stats::prop.test(correct=FALSE)` · closed_form · OE 4sf / EI7 no
- Method differences: OpenEpi skips mid-p/Fisher when n > 100 001 (device safeguard — Epiora has no such cap). OpenEpi's conf list is site-wide 20–99.99%; Epiora uses the §5.3 list.

## two_by_two  (family: counts)

- Sources: OpenEpi page <https://www.openepi.com/TwobyTwo/TwobyTwo.htm> (+ `TwobyTwo.js`, `js/MartinStats.js`) · EI7 StatCalc `EpiDashboard/StatCalc/TwoByTwo.xaml(.cs)` — same statistic family, different output set (see `two_by_n` for the EI7-format calculator)
- Inputs:

- Outputs, per stratum and crude:
  - `calc.two_by_two.<s>.chisq.uncorrected.{value,p_1t,p_2t}` · uncorrected χ² (df 1) · `stats::chisq.test(correct=FALSE)` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.chisq.yates.{value,p_1t,p_2t}` · Yates-corrected χ² · `stats::chisq.test(correct=TRUE)` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.chisq.mantel_haenszel.{value,p_1t,p_2t}` · Mantel–Haenszel χ² · `stats::mantelhaen.test(correct=FALSE)` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.fisher_exact.{p_1t,p_2t}` · Fisher exact test · `stats::fisher.test` · iterative · OE fmtPValue / EI7 no
  - `calc.two_by_two.<s>.midp_exact.{p_1t,p_2t}` · mid-p exact test · `exact2x2::exact2x2(tsmethod="midp")` · iterative · OE fmtPValue / EI7 no
  - `calc.two_by_two.<s>.risk.exposed.{est,lower,upper}` · risk in exposed, Taylor CI · `epiR::epi.2by2` (risk strata) · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.risk.unexposed.*` and `calc.two_by_two.<s>.risk.overall.*` · as above · epiR::epi.2by2 · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.risk_ratio.{est,lower,upper}` · RR, Taylor-series log CI · `epitools::riskratio(method="wald")` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.risk_difference.{est,lower,upper}` · RD, Wald CI · `epiR::epi.2by2` (ARisk) · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.odds_ratio.{est,lower,upper}` · OR, Taylor-series log CI · `epitools::oddsratio(method="wald")` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.cmle_or.{est,lower_midp,upper_midp,lower_fisher,upper_fisher}` · conditional MLE OR with mid-p and Fisher exact limits (Martin/David's exact module) · `epitools::or.midp` + `exact2x2::exact2x2` · iterative · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.etiologic.{efp,efe,pfp,pfe}.{est,lower,upper}` · etiologic/prevented fractions (risk-based) with CIs · `epiR::epi.2by2` (PARisk/AFEst) · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.<s>.etiologic_or.{efp_or,efe_or,pfp_or,pfe_or}.*` · same fractions derived from OR · `fixtures/R/methods/tables.R::ef_or` — Rothman & Greenland formulas as in `TwobyTwo.js` · closed_form · OE 4sf / EI7 no
- Outputs, adjusted (strata > 1):
  - `calc.two_by_two.adjusted.mh_chisq.{value,p}` · Mantel–Haenszel summary χ² · `stats::mantelhaen.test` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.adjusted.mh_or.{est,lower,upper}` · MH OR, Robins–Breslow–Greenland CI · `epiR::epi.mh` (method="OR") · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.adjusted.direct_or.{est,lower,upper}` · directly adjusted OR, Taylor CI · `fixtures/R/methods/tables.R::direct_adjust` — Rothman & Greenland direct pooling · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.adjusted.direct_rr.*`, `.direct_rd.*`, `.mh_rr.*` · direct/MH adjusted RR and RD, Taylor CIs · `fixtures/R/methods/tables.R::direct_adjust` / `epiR::epi.mh` · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.adjusted.breslow_day.{or_chisq,or_p,rd_chisq,rd_p,rr_chisq,rr_p}` · Breslow–Day interaction tests · `fixtures/R/methods/tables.R::breslow_day` — Breslow & Day 1980 (engine already has `stats::breslow_day`) · closed_form · OE 4sf / EI7 no
  - `calc.two_by_two.adjusted.cmle_or.*` · stratified CMLE OR, mid-p/Fisher limits (MartinStats strata loop) · `exact2x2::exact2x2` on pooled table / methods `tables.R::stratified_cmle` · iterative · OE 4sf / EI7 no
- Method differences: OpenEpi skips exact stats when numbers are large ("exact calculations skipped"); Epiora computes them. Risk-based vs odds-based sections are both emitted; `study_type` only controls display. EI7's StatCalc version outputs the `two_by_n` set instead.

- Sources: OpenEpi page <https://www.openepi.com/DoseResponse/DoseResponse.htm> (+ `DoseResponse.js`) · EI7 StatCalc `EpiDashboard/StatCalc/ChiSquareControl.xaml(.cs)` (5 fixed rows)

- Outputs, per stratum and overall:
