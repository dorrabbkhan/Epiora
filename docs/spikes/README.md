## Inputs v0.2 needs

- **Fixture oracle:** `fixtures/2x2/oswego_vanilla.json` (shape fixed by
  `fixtures/schema/fixture.schema.json`; regenerated byte-identically only via
  `Rscript fixtures/generate.R` under `renv.lock`, R 4.5.2 + epitools
  0.5-10.1). Engine tests consume it at tolerance 1e-9. R-version drift is
  guarded by the spike-fixtures workflow.
- **Epi Info 7 CI reference:** `.pgm`s must `READ '.mdb':table` directly —
  shipped `.prj` connection strings are undecryptable on both source-built and
  official binaries. The Oswego data table is `Oswego12`. `Analysis.exe
  <file>.pgm7` + a final `QUIT` is the headless route; "no output file" is the
  failure signal. No Epi Info binaries are committed (D2, Apache-2.0 with
  notice).
- **`epiora-mdb` recipe:** libmdb (mdbtools 1.0.1) `--disable-glib
  --disable-iconv` under Emscripten; the produced API is
  `mdb_version`/`mdb_tables`/`mdb_export_csv` (~61 KB gz). LGPL: ship libmdb as
  a separately replaceable wasm artifact. `mdb_version` returns `ACE12`–`ACE18`
  for `.accdb` — widen the interface union when `.accdb` import lands.
- **Local store:** sqlite-wasm on OPFS for storage; DuckDB-wasm (~8.0 MB gz)
  lazy-loaded for analytic queries, outside the §12.8 first-load budget.
  Engine OOM is recorded as an error row, never fatal (the query-bench
  harness pattern).
- **§11.1 field crypto:** `fieldCrypto.encrypt`/`decrypt` produced by the D6
  spike (AES-GCM 256, PBKDF2-SHA256 600k iterations, base64 salt‖iv‖ct). OPFS
  absence is a supported degraded mode — report it, never throw. Whole-DB
  browser encryption stays out; Tauri keeps SQLite3MultipleCiphers.
- **WebR:** hosted-only for advanced methods on mobile; lazy-load elsewhere.
  HTTP caching does not retain R.wasm (~12.3 MB re-downloaded per load); any
  revisit should measure Cache Storage/service-worker pinning.
- **Sync (v2.0 spec inputs):** the §7.3 outline is validated; the v2.0 spec
  must add tombstones, form-version migration and persistence, per-change
  apply status (to avoid spurious self-conflicts), and conflict delivery to
  non-pushing devices. Electric remains the D8 fallback.
- **Tauri (v0.3 inputs):** shell proven on Android emulator and iOS simulator;
  the DB key must be applied at connect time (plugin pragma support, a fork,
  or our own wrapper) — the spike's per-call `PRAGMA key` is a workaround.
  `src-tauri/gen/` is generated in CI, not committed.
- **D7 reference device:** the owner-chosen proxy is "Pixel emulator + Chrome
  DevTools 4× CPU throttle and Slow 4G"; a physical ≤ 4 GB Android run is
  deferred to a later plan (`node measure.mjs --cdp <endpoint>` over Chrome
  remote debugging).
