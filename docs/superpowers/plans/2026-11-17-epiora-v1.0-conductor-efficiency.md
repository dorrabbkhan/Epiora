# Epiora v1.0 — Conductor efficiency (Tasks 0a, 0b) Implementation Plan

**Goal:** cut the conductor's (Claude Code, Opus) token spend per task by roughly half before v1.0 Task 11,
without changing what the conductor judges or escalates. Ports babelgate v1.5 Tasks 0a/0b
(babelgate PRs #113, #114, follow-ups #117, #119) and adapts every check to Epiora's rules.

**Spec:** none — build process only, no product code. The "Analysis" section below is the evidence; CLAUDE.md
"Judgment rules", "Spike-specific rules" and "Owner-only actions" are the rules the scripts encode, unchanged.

**Tech Stack:** bash; TypeScript run by Node 24's built-in type stripping (`node scripts/conductor/x.ts`,
imports with explicit `.ts` extensions, no enums/namespaces); tests with `node --test`. **No new
dependencies, no `package.json` anywhere.**

**Prerequisite (owner):** merge this plan before Task 0a merges (0a is stacked on it).

**What changes** (each line → task):
1. One `judge.sh` runs every mechanical judgment rule on the PR diff and prints ≤ 60 lines → 0a.
2. `devin.sh` prints only the last 30 lines + `PR_URL:`/`STOP:`; full output stays on disk; empty-prompt guard;
   checkout restore; body inside `main()` → 0a.
3. `build-prompt.sh` assembles Devin prompts mechanically → 0a.
4. `wait-ci.sh` blocks on CI and prints only the final table + failing-job tails → 0a.
5. `usage-report.sh` measures it, with Epiora attribution (E6) → 0a.
6. Lean starting context (`.claude/settings.json`), Haiku `log-reader` subagent, bounded waits that fit the
   10-minute tool limit, one fresh headless session per task (`run-plan.sh`) with an explicit tool
   allow-list, `RESULT:` line, docs → 0b.

**Target:** v1.0 Tasks 11+ median ≤ $4.00/task (from $7.41); first-turn input ≤ 20k in the plain CLI (E8); the first T3 Code session after 0b merges confirms the six tools are gone there too.
After three product tasks the conductor posts the before/after comparison on the third task's status comment.

## Global Constraints

- **Judgment is unchanged.** Scripts report `PASS`/`FLAG`/`N/A`; a FLAG is never auto-waived; anything a
  script cannot parse is a FLAG naming the check, never a silent PASS. CLAUDE.md "Judgment rules" text stays
  word-for-word; only "The loop" and the commands change.
- **No product changes:** nothing under `crates/`, `app/`, `spikes/`, `fixtures/`, `store/`, `.github/`.
- **Owner-only stays owner-only:** no merge, no approve, no ruleset/branch-protection change, no workflow
  edit, no `--dangerously-skip-permissions`, no `bypassPermissions` in any committed setting or script.
- **Privacy:** `usage-report` prints aggregates only — never prompt text, tool inputs or outputs.
- **No network in tests.** `gh` is never called by `node --test`; tests use seeded diffs and synthetic logs.
- Files ≤ ~400 lines (split as babelgate did: `diff-parse.ts`, `judge-checks.ts`, `judge.ts`).
- Reference implementation (read-only, untracked, never committed): `.conductor-ref/babelgate/` in the
  checkout. Port, don't copy blindly: every check below is Epiora's, not babelgate's.

- Check ids, in this order:
  1. `fixtures` — any file under `fixtures/`, any `**/golden/**`, any file whose name contains `baseline`.
  2. `numbers` — a numeric literal changed (removed line ↔ added line in the same hunk) on a line matching

     file; and any changed number inside the plan or spec. Prints file:line and old → new.
  3. `assertions` — a hunk removes more `assert*!(`/`expect(`/`assert.`-calls than it adds; `assert_eq!`/
     `assert_biteq!` → `assert!` swaps; `toEqual|toStrictEqual|toBe(` → `toMatchObject|objectContaining|
     toContain|toBeTruthy` swaps.
  4. `skips` — added `#[ignore`, `.skip(`, `.only(`, `test.fixme`, `.todo(`, `skipIf`, `describe.skip`,
     `it.skip`, `skip(` in test files.
  5. `files-block` — parses the task's `**Files:**` block (`### Task <N>:` section; globs and bare file names
     allowed, a bare name resolved by unique basename — babelgate #117/#119); passes when every extra file is
     named (path or unique basename) in a `docs/decisions.md` hunk of the same diff.
  6. `spikes-import` — an added line outside `spikes/` that references `spikes/` in a `use`, `mod`, `path =`,
     `import`/`require`, or a Cargo/workspace member entry.
  7. `licences` — added dependency lines in `Cargo.toml`, `Cargo.lock`, `package.json`, `package-lock.json`
     matching `gadm|powersync|sqlite-?see|sqlite3-see`; any change to `deny.toml` or the npm licence
     allow-list (FLAG for the conductor to look, not a verdict).
  8. `spike-report` — when `docs/spikes/**` changed: runs `scripts/check-spikes.sh` and reports its result;
     a Measurements line containing a digit with no `http` link or backticked command on the same line →
     FLAG. N/A otherwise.
  9. `secrets` — key/token patterns (never echo the matched text); added `console.log`/`dbg!`/`println!` of
     request or record bodies.
  10. `diff-stat` — file list of the PR vs the files the Devin session claimed (`git diff --stat` block in
      `--claimed`, default the newest `~/epiora-conductor/<v>-task<N>/*.out.md`); N/A when none.
  11. `owner-gate` — PR title `[OWNER GATE]`/`[OWNER REVIEW]`; the task's Gate column in the Task Index
      containing `OWNER GATE`, `OWNER REVIEW` or `(human step)`; touched `.github/**`,
      `docs/superpowers/specs/**`, `LICENSE*`, `AGENTS.md`, `fixtures/**`, `deny.toml`.

- **Bounded waits** (a foreground tool call is capped at 10 minutes and headless `claude -p` has no
  `t3_background_wait`): `DEVIN_DETACH=1 devin.sh …` starts the session detached (`setsid nohup`), writes
  `<out>.md`, then `<out>.rc` on exit, and prints the `.out.md` path. `wait-for.sh <out.md> [max_s=540]`

  `PENDING <n> lines` and exits 4. `wait-ci.sh` honours `WAIT_CI_DEADLINE_S` the same way (exit 4, the watch
  left running is killed; a re-call resumes). Interactive T3 Code sessions may still use
  `run_in_background` + one `t3_background_wait`.
- `run-plan.sh <version> <from> <to>`: tasks in Task Index order (ids like `0b`, `11`, `7a`, contiguous range by
  table position; Task Index parsed by header name). Model from the **Conductor** column (`Opus` → opus,
  `Sonnet` → sonnet, absent column → opus with a warning, anything else → error). Runs
  `claude -p "/conduct <version> <id>" --model <m> --allowedTools "<headless-tools.txt joined by ,>"` with
  output to `~/epiora-conductor/<v>-task<id>/headless-<stamp>.out`, then reads the task's
  `conductor-log.md`: only a line appended by **this** session (line count recorded before) counts.
  `RESULT: READY <PR>` → waits in bash (`gh pr view <PR> --json state`, every `RUN_PLAN_POLL_S`=300 s, no
  Claude calls) until `MERGED` (`CLOSED` → stop); `ESCALATED|GATE|FAILED` or no new line → stop + `notify.sh`.
  `DRY_RUN=1` prints the `claude -p` command and exits 0. Never merges.
- `headless-tools.txt`: one spec per line (`#` comments stripped), mirroring `.claude/settings.json` `allow`

- `.claude/agents/log-reader.md`: `model: haiku`; tools `Read, Bash(grep:*), Bash(tail:*), Bash(gh run view:*)`;

## Review Focus

1. **`judge.sh` meets a diff it can't parse** (binary file, rename-only, a 5k-line truncated diff). Expected:
   a FLAG naming each check that could not run, exit 1, never a silent PASS. → 0a
   `"unparseable diff flags, never passes"`.
2. **A tolerance quietly widened** (`1e-9` → `1e-8` in a test or `TOLERANCE` constant, a size budget raised).
   Expected: `numbers` FLAG with old → new and file:line. → 0a `"tolerance number change flags"`.
3. **A headless session crashes or is denied a tool** and writes no `RESULT:` (or an old `READY` sits at the
   end of the log). Expected: `run-plan.sh` stops and notifies; never starts the next task. → 0b stale-RESULT test.
